# Chess — Offline PWA

Free, local-first chess app. No server, account, ads, or external libraries. Includes legal moves, castling, en passant, promotion, checkmate, stalemate, repetition and move-count draws, three offline opponent difficulty settings, local two-player mode, and optional clocks.

## Notes
- Clocks pause while the app is closed or in the background; this is intended for casual offline play.
- Games are saved only on this device/browser. Clearing site data removes them.
